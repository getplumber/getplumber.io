> **Devs don't write CI/CD by hand anymore, they prompt it. We read the pipeline history of 500 public repos from 277 Y Combinator startups: in 18 months, AI agents went from zero to nearly one in four workflow changes. Then we graded every one of those pipelines.**

## How we did it

- **The cohort.** Every company from the YC batches of 2024, 2025 and 2026 whose GitHub organization we could verify: the organization's website must match the company's, or the company's own site must link to it under its own name. That gives 277 startups with at least one active public repository running GitHub Actions.
- **The repos.** For each startup we took its most-starred repository with workflows and activity in the last 12 months, then filled up to 500 with their next most-starred ones (at most three per company). Median: [TBD] stars.
- **The AI signal.** We read every commit that touched `.github/workflows/` since January 2024 (22,475 commits) and flagged those carrying a coding agent's signature: Claude Code's `Co-Authored-By` trailer, the Copilot coding agent, Cursor, Devin, Codex, Gemini.
- **The grade.** Each repository was analysed by [Plumber Radar](/radar) with the open-source [Plumber CLI](https://github.com/getplumber/plumber) and given a [Plumber Score](/blog/plumber-score-cicd-security-standard) from A to E. One Critical finding forces an E.
- **Aggregates only.** No repository or company is named in this report. Every company in the cohort received its own grade privately.

The AI signal is a **floor, not an estimate**. A commit only counts if the agent left its signature. Copy-pasting a ChatGPT answer, accepting an autocomplete, or committing an agent's output by hand leaves no trace, so the real share is higher.

- **Through all of 2024, not a single signed AI commit** touched a workflow file in the cohort.
- **The jump came in early 2026.** The share quadrupled between the last quarter of 2025 and the first of 2026, and has stayed between a fifth and a quarter of all pipeline changes since.
- **It is recent everywhere.** For half of the repositories with AI-authored pipeline changes, the first one landed in **April 2026 or later**.
- **It is already the default for many teams.** In 93 of the 500 repos, the most recent change to the pipeline was AI-authored.

Pipelines are the part of the codebase developers like least and review least. They are exactly what people hand to an agent first.

## Why AI writes insecure pipelines

An agent asked to "add a workflow that builds and deploys to AWS" does what it learned from millions of public repositories, and most public pipelines are insecure: in our [State of CI/CD Security 2026](/blog/state-of-cicd-security-2026), 76% of 15k+ public projects graded D or E.

- **It copies the most common pattern, not the safest one.** `uses: actions/checkout@v4` is everywhere in its training data; a pinned SHA with a version comment is rare.
- **It optimizes for "the pipeline is green".** Narrowing token permissions or pinning dependencies never makes a build pass, so it never comes up unless you ask.
- **Nobody reviews the YAML.** A pipeline change in a 40-file PR gets skimmed. The agent wrote it, CI passed, it ships.
- **It is the same attack surface as before, produced faster.** Unpinned third-party actions and over-broad tokens are exactly how [tj-actions/changed-files](/blog/tj-actions-compromised) and [Shai-Hulud](/blog/shai-hulud) spread.

None of this is the developer's fault, and none of it is hard to fix. The fix is a review step that reads the YAML the agent wrote.

## Grade your own pipeline

1. **Get your grade.** Install the [Plumber CLI](https://github.com/getplumber/plumber) (`brew install getplumber/plumber/plumber`) and run `plumber analyze github.com/OWNER/REPO`, or `plumber analyze` from your repository. `--score-point` shows where every point went.
2. **Let the agent check the agent.** If an AI writes your workflows, run Plumber in the same PR, so the YAML it produced is graded before it merges.
3. **Publish it.** Add `score-push: true` to get a verifiable [score page](/docs/plumber-score), and a badge for your README once you hit an A.
