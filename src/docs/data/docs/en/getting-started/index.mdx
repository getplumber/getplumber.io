## Install

On macOS and Linux, with [Homebrew](https://brew.sh):

```bash
brew tap getplumber/plumber
brew install plumber
```

No Homebrew? [All install methods](/docs/cli/installation)

## Get your first score

Authenticate with your provider:

<CardGrid>
  <Card title="GitHub" icon="tabler/brand-github" badge="GH_TOKEN" links={[{ text: "Details", href: "/docs/cli/github#authentication" }]}>
    - Already logged in with the `gh` CLI? Nothing to do, Plumber finds it automatically.
    - Otherwise set `GH_TOKEN`.
  </Card>
  <Card title="GitLab" icon="tabler/brand-gitlab" badge="GITLAB_TOKEN" links={[{ text: "Details", href: "/docs/cli/gitlab#authentication" }]}>
    - Set `GITLAB_TOKEN`.
  </Card>
</CardGrid>

Then run from any repo that has GitHub Actions workflows or a `.gitlab-ci.yml`:

```bash
cd path/to/your/repo
plumber analyze
```

The report ends on your score. Above it, Plumber lists the **attack paths** it
found (who can get into one of your jobs, and what they reach there) and the
individual findings, each with one fix:

<ScoreReport
  score={34}
  grade="D"
  status="failed"
  gate={100}
  worstCase="as anyone with write access to `main`, an attacker can execute code to write to security events and request an OIDC token (attack path 1: main)"
  fix={{
    text: "move to a version without the advisory",
    detail: "action tj-actions/changed-files@2d756ea4c53f",
    delta: "+15 pts",
    result: "49 / 100 (D)",
  }}
/>

<Aside variant="tip" title="Next step">
  Run `plumber explain -a 1` to see every finding behind attack path 1.
</Aside>
