## The attestation key

Plumber signs each [official organization](/docs/plumber-score/official-organizations)'s attestation with one ECDSA P-256 key. Its public half is published here and at [`/plumber-score/plumber-score.pub`](/plumber-score/plumber-score.pub). Every signature is also recorded in the public Rekor transparency log.

A repository's own row is not signed with this key. It carries the Sigstore bundle its own GitHub Actions job produced, verifiable against GitHub's identity alone: see [Verify an attestation](/docs/plumber-score/verify-an-attestation).

The key id is the base64 of the sha256 of the key's DER encoding. The same value sits in every attestation under `predicate.keyId`, so a verifier knows which key to use before trying it:

```bash
openssl ec -pubin -in plumber-score.pub -outform DER 2>/dev/null | openssl dgst -sha256 -binary | base64
```

## Rotation

A new key is published on this page, with its validity date, before it signs anything. The previous key stays listed with an end date, so attestations signed before the switch keep verifying. An attestation always names its key by id. The private key never leaves Plumber's production environment and is never shared with an organization.
